Frequently Asked Questions

Everything You Need to Know About SRT Translation

Find quick answers to common questions about subtitle timing preservation, AI pacing modes, supported languages, and security.

Which languages are supported by SRTtranslator?

SRTtranslator supports over 40 global languages including Bengali, English, Spanish, Hindi, Urdu, Arabic, French, German, Japanese, Korean, Chinese (Simplified), Portuguese, Russian, Italian, Turkish, Indonesian, Vietnamese, Thai, Tamil, Telugu, Marathi, Gujarati, Malayalam, Punjabi, Persian/Farsi, Dutch, Polish, Swedish, Norwegian, Danish, Finnish, Greek, Hebrew, Czech, Romanian, Hungarian, Ukrainian, Malay, and Filipino/Tagalog.

How do I translate an SRT subtitle file online for free?

Simply upload your .srt file to SRTtranslator, select your target language from the 40+ available options, choose your desired subtitle pacing preset (e.g. Glance Speed or Fast Reading), provide your free Google Gemini API key, and click 'Translate Subtitles Now'. Your localized SRT file will be ready and automatically downloaded within seconds.

Will the subtitle timestamps, timecodes, and formatting stay 100% synchronized?

Yes, completely. SRTtranslator isolates only the spoken dialogue text during translation while preserving every millisecond of the original start and end timecodes (00:00:00,000 --> 00:00:00,000), line sequence numbering, and HTML styling tags (like <i> and <b>). It also includes an automatic overlap collision resolver.

What is Glance-Speed Subtitle Pacing and the 2nd-Pass AI Condenser?

Glance-Speed pacing is an advanced subtitle optimization mode engineered for fast-paced movies, anime, and YouTube videos. It keeps dialogue lines down to 1-4 punchy words (~0.5-1s read time). The 2nd-pass AI Condenser allows you to re-evaluate already translated subtitles, eliminating conversational padding and wordy grammar so viewers can absorb the subtitles in the blink of an eye without missing any visual action on screen.

How does SRTtranslator ensure natural, cinema-grade dialogue across different languages?

Unlike standard machine translation tools that produce rigid, literal translations or inappropriate pronouns, SRTtranslator enforces language-specific cinematic localization rules. For example, in Bengali it strictly prevents disrespectful pronouns (avoiding 'তুই') and uses polite, natural speech ('তুমি/আপনি'); in Hindi/Urdu it prioritizes respectful dialogue ('तुम/आप'); in Spanish and French it maintains authentic conversational tone ('tú/usted', 'tu/vous'); and in Japanese it applies natural spoken phrasing matching character personality.

Is my subtitle file, translated text, and Gemini API key secure?

100% private and secure. SRTtranslator runs completely client-side in your web browser. Your subtitle scripts, translations, and Gemini API keys are never sent to or stored on any intermediary backend servers. Your API key remains saved only in your browser's private local storage.

Is there any file size limit, subtitle line limit, or cost?

SRTtranslator is completely free with no file size limits or line caps. By connecting your free Google Gemini API key (which includes a generous free tier from Google AI Studio), you can translate full-length feature films, multiple TV episodes, documentaries, and long YouTube videos seamlessly.

Can I edit individual subtitle cards or re-shorten specific lines?

Yes. In the Subtitles Card View and Side-by-Side Comparison tabs, each subtitle card displays live reading speed metrics (word count and estimated reading seconds) and provides an instant 'Shorten' button to compress individual lines without needing to re-translate the entire file.
